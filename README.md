# Киноинтуиция

Статический мобильный веб-игровой проект на чистом HTML/CSS/JS.

## Что внутри

- `index.html` — приложение.
- `styles.css` — мобильный UI и анимации.
- `app.js` — логика игры, подсчёт баллов и статистика.
- `data.js` — сериализованный набор из загруженного CSV (50 сериалов).

## Публикация на GitHub Pages

1. Создайте публичный или приватный репозиторий.
2. Загрузите эти четыре файла в корень репозитория.
3. В GitHub откройте **Settings → Pages**.
4. Выберите публикацию из ветки `main` и папки `/root`.
5. Откройте выданный GitHub Pages URL.

Сервер и API не нужны.

## Правила

В каждой игре случайно выбираются 10 уникальных сериалов. Рейтинг из `data.js` используется только после нажатия «УГАДАТЬ». Максимум — 10 000 баллов.

## Источник данных

Приложение собрано на основе загруженного CSV-файла пользователя с данными сериалов Кинопоиска.
